# Research

Research notes connect primary sources to Harmoneasy design decisions. A paper's findings, an existing product's behaviour, and a proposed Harmoneasy experiment are different kinds of evidence and are labelled accordingly.

- [Ensemble: evidence and current design](ensemble-transformer.md) — the one-key ensemble goal, annotated sources, implementation mapping, and limitations.
- [Ensemble: next experiments](ensemble-next-experiments.md) — further ideas, priorities, and a practical evaluation plan.

The ensemble review was updated on 2026-11-21. Sources are linked rather than copied into this repository; publication years refer to the works themselves, not search-engine crawl dates. These notes do not establish that the classroom interaction has been validated with users.
